# React Storybook Example with Radix UI

React 컴포넌트를 Storybook으로 보여주는 예시 프로젝트입니다.

## 설치

```bash
npm install
```

## 개발 서버 실행

```bash
npm run dev
```

## Storybook 실행

```bash
npm run storybook
```

Storybook은 `http://localhost:6006`에서 실행됩니다.

## Storybook 빌드

```bash
npm run build-storybook
```

## 포함된 컴포넌트

- **Button**: Radix UI Button을 사용한 버튼 컴포넌트
- **Dialog**: Radix UI Dialog를 사용한 다이얼로그 컴포넌트

## 기술 스택

- React 18
- TypeScript
- Vite
- Storybook 8
- Radix UI
